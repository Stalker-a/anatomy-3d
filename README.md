# Анатомия 3D

Интерактивный 3D-атлас для изучения анатомии по «Атласу анатомии человека» Р. Д. Синельникова.
Устроен как каталог: **Главная → Регион → Модель**. Модель — это глава книги (например, «Коленный сустав»):
3D-сцена с ракурсами (спереди, сзади, сбоку, медиально, сверху, вращение), описание с таблицей фактов
(тип сустава, кости, движения), структуры по группам (суставы, кости, связки, диски и мениски) с объяснением
каждой, тест и похожие модели. Поиск по всем терминам — в шапке.

Термины (русский и латынь) взяты из книги, объяснения написаны своими словами по её тексту.
Каждый термин привязан к модели:

- **3D-объект** — у структуры есть своя модель (связка, капсула, диск, мениск…);
- **точка на кости** — деталь кости (головка, суставная поверхность, отверстие);
- **показаны кости** — своей модели нет, подсвечиваются кости, которые образуют соединение.

Есть режим «Тест»: «Что выделено?» и «Найди на модели».

```
npm install

npm run build    # статический сайт в dist/
```

## Как собирается раздел

Книги, сканы и распознанный текст в репозиторий не попадают: они лежат в `work/` и `books/` (папки в `.gitignore`).

1. `scripts/ocr_pages.py` — OCR страниц тома (Tesseract, rus+lat) в `work/ocr/`.
2. `scripts/extract_terms.py` — кандидаты «русский термин, latin term» с номерами страниц и рисунков.
3. `pipeline/<раздел>.terms.txt` — вычищенный вручную список терминов по главам с привязкой к модели.
   `pipeline/<раздел>.notes.txt` — объяснения к главам и терминам (формат описан в начале файла),
   `pipeline/regions.json` — регионы каталога, `pipeline/bones_ru.py` — русские названия костей.
4. `scripts/export_section.py` — экспорт структур из Z-Anatomy (Blender, без автозапуска скриптов из файла) в сжатый `.glb`.
5. `pipeline/build_section.py` — проверяет все привязки, собирает `public/data/<раздел>.json` и выдаёт отчёт о покрытии.
6. `tools-dev/thumbs.mjs <url>` — превью карточек в `public/thumbs/` (при запущенном `npm run dev`).
7. `tools-dev/check.mjs <url> <папка> [mobile]` — проверка сайта в Chrome (ноутбук и телефон) со снимками экрана.
